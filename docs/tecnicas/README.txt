# Carpeta: docs/tecnicas/

Coloca aqui las imagenes o GIFs de cada tecnica de Hapkido.
El sistema las cargara automaticamente en las tarjetas del glosario.

## Formatos aceptados
- .gif — GIF animado (recomendado para tecnicas en movimiento)
- .jpg / .jpeg — Foto estatica
- .png — Imagen estatica
- .webp — Formato moderno

El sistema busca primero .gif, luego .jpg, .png, .webp.

## Convencion de nombres

El nombre del archivo debe coincidir exactamente con la tabla siguiente.

TECNICAS Y ACCIONES:
makgi, chagi, jumok, sonnal, palgup, palmok, kkeokgi, deonjigi,
nakbeop, chigi, jireugi, twigi, anja, bal-bakkwo, gureugi, iroseo,
gyeokpa, pumsae, seogi, juchum-seogi, ap-seogi, ap-gubi,
dwit-gubi, beom-seogi, koa-seogi

## Reglas
1. Todo en minusculas.
2. Los espacios se reemplazan con guiones (-).
3. Sin tildes ni caracteres especiales en el nombre del archivo.

## Ejemplo
deonjigi.gif -> docs/tecnicas/deonjigi.gif
nakbeop.jpg  -> docs/tecnicas/nakbeop.jpg

## Tamano recomendado
- GIF animado: max 5 MB
- Imagen estatica: max 500 KB
- Dimensiones sugeridas: 400x300 px o 400x400 px
